The Sample Novel

The desk was wider than any phone screen. Prose sits in a measured column, framed by cool sea-mist neutrals and Swiss hairlines; vermilion still marks only what matters.

Navigation lives in the header and the left index. Tabular chapter numbers, an eight-pixel rhythm, and quiet grid ticks keep the layout honest without decoration.

Warm paper, sumi ink, one warm accent — with slate-teal for the grid and the labels.

Scroll the column; the index stays fixed. Arrow keys move between chapters.

Palette: vermilion primary + sea-slate metadata + mist surfaces. Open in a browser to review light/dark.
